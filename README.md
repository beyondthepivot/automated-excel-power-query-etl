Automated Excel PowerQuery ETL

Overview

Built an automated Excel Power Query solution to consolidate and transform energy reporting data from multiple source files.

The solution combines, cleans, validates, deduplicates, and standardizes data into a single reporting dataset while automatically handling different reporting intervals (5-minute and 30-minute series).

Key Features:
- Multi-file import from a source folder
- Automated data cleansing and validation
- Duplicate record removal
- Automatic interval detection
- Aggregation of 5-minute data into 30-minute intervals
- Standardized reporting output
- One-click refresh process for end users

User Process:
1. Add or replace source files
2. Open the Excel template
3. Click "Refresh All"
4. Receive updated output
